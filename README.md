# 9014 · 战棋

**v0.9 Public Playtest**

一款以科研权谋世界观为灵感的多阵营策略战棋公开测试版。

## 当前版本

- 四种可选势力与差异化胜利条件
- 随机地图、隐藏事件、卧底、BOSS 与中立势力
- ZY 中立 NPC
- 新手教程与开始界面
- 浏览器本地存档，可继续游戏

## 测试说明

当前仍为公开测试版本，游戏数值、AI、胜利条件、UI 与机制可能继续调整。

游戏仅借鉴《9014 科研权谋》的部分世界观氛围与创作灵感，玩法、阵营关系与结局均为独立改编，不代表小说原剧情。
