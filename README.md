## 在线试玩

直接打开固定网页即可游玩：

**https://zsb-xxx.github.io/9014-game/**

建议优先使用 Chrome、Edge 等现代浏览器。游戏存档保存在当前浏览器的本地存储中；只要不清除该网站的浏览器数据，再次打开同一网址即可使用“继续游戏”。

## 如何下载到本地

如果希望把游戏源码下载到电脑：

1. 打开本仓库首页：`https://github.com/zsb-xxx/9014-game`
2. 点击绿色 **Code** 按钮。
3. 选择 **Download ZIP**。
4. 下载完成后解压 ZIP 文件。

> 注意：当前 GitHub Pages 部署版为了便于维护，将样式和脚本拆成了多个文件，`index.html` 会读取同目录下的 `css-*.txt`、`body-*.txt` 和 `js-*.txt`。因此不要只单独下载 `index.html`。

### 本地运行

最简单的方式仍然是直接使用上面的在线试玩地址。

如果需要在本机离线/本地运行，请在解压后的游戏目录启动一个本地 HTTP 服务，然后访问 `index.html`。例如电脑已安装 Python 时：

```bash
python -m http.server 9014
```

然后在浏览器打开：

```text
http://localhost:9014/
```

关闭命令行窗口即可停止本地服务。

> 直接双击 `index.html` 可能受到浏览器 `file://` 本地文件访问限制，导致分拆资源无法载入，因此不作为推荐运行方式。
